# Редактирование контента

Все правки делаются в двух файлах: `assets/js/config.js` и `assets/js/data.js`. HTML трогать не нужно.

## Цена или описание услуги
`assets/js/data.js` → `SERVICES`. Поля: `title`, `price` (₽ в минуту; `0` = «Бесплатно»), `text`, `img`, необязательный `badge`.
## Добавить услугу
Положите фото в `assets/img/` (webp, ширина ~800 px), добавьте объект в `SERVICES`. Карточка появится сама.
## Отзывы
`REVIEWS`: `name`, `lvl`, `date`, `text`. Копируйте текст без правок. Новые отзывы добавляйте в начало массива. Показывайте 6–10 лучших.
## Галерея
Положите фото в `assets/img/`, добавьте `['имя-файла-без-расширения', 'описание']` в `GALLERY`. Первые 7 записей показываются плитками мозаики (первая плитка самая крупная, седьмая со знаком «+N ещё фото»), остальные открываются в просмотре на весь экран.
Не публикуйте фото с читаемыми номерами автомобилей: закройте номер перед загрузкой.
## Оптимизация фото
```bash
python3 -c "from PIL import Image; im=Image.open('in.jpg').convert('RGB'); im.thumbnail((1000,1000)); im.save('assets/img/name.webp','WEBP',quality=72)"
```
## Контакты и соцсети
`config.js`: `phone`, `phoneRaw`, `telegram`, `vk` (основная соцсеть, кнопки по всему сайту), `mapUrl`.
## Яндекс.Метрика
1. Создайте счётчик на metrika.yandex.ru. 2. Впишите номер в `metrikaId`. 3. В Метрике создайте JavaScript-цели с идентификаторами: `call`, `route`, `telegram`, `vk`, `reviews`. Данные пойдут автоматически.
## Видео
Положите `hero.mp4` (желательно и `.webm`) в `assets/video/` и включите `hero: true` в `config.js` → `videos`. Пока флаг `false`, показывается фото. Промпт: [VIDEO-PROMPTS.md](VIDEO-PROMPTS.md).
## Акции
Акции и новости ведутся в группе ВКонтакте (на сайте есть ссылка на группу).

## Логотип студии в подвале
Файл `assets/img/studio-logo.png`, ссылка и подпись в блоке `.studio` в `index.html`. Ведёт на https://setchatkaglaza.github.io/setchatkaglaza/.
