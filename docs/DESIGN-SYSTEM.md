# Дизайн-система

**Идея:** строгий деловой стиль по логотипу: чёрный и серебро, один жёлтый акцент только для цен и главного действия, тонкие линии вместо теней, один шрифт. Движение спокойное и плавное.

## Цвета (CSS-переменные в `:root`)
| Токен | Значение | Роль |
|---|---|---|
| `--bg` / `--bg2` / `--card` | #08090b / #0d0f12 / #13161a | фоны |
| `--chrome` | градиент белый-серебро | заголовки-акценты, активные кнопки |
| `--sig` | #ffc61a | цены, главные кнопки |
| `--blue` | #3aa0ff | отблеск воды |
| `--vk` | #0077ff | кнопки ВКонтакте |
| `--ok` | #3ddc8f | «открыто», бесплатно |

## Шрифты
Один шрифт **Golos Text** (400–700, кириллица) с запасными системными. Цифры табличные.
## Компоненты
Кнопки `.btn` · факты `.facts` · табло цен `.board` · строки цен со шкалой `.pr` и фото `.pick__view` · терминал `.term` · карточки боксов `.bay` и схема `.plan` · список условий `.adv` · мозаика `.mos` · отзывы `.rv` · нижняя панель `.dock`.
## Движение
Заголовок выезжает из-под линии, по фасаду проходит световой блик, фон слегка следует за курсором, табло цен подсвечивает строки по очереди, шкалы цен вырастают при появлении, терминал сам показывает цикл мойки, двери на схеме «открываются», плитки мозаики появляются по очереди, шапка прячется при прокрутке вниз, колёсико мыши на ПК прокручивает с инерцией. При `prefers-reduced-motion` вся анимация отключается.
## Адаптив
Вёрстка mobile-first: базовые стили для телефона, расширение с 900 px. Минимальный кегль 14 px (основной текст 16–17 px), зоны нажатия не ниже 48 px, на телефоне режимы идут сеткой 2 колонки под фото, нижняя панель действий.
## Доступность
Пропуск к содержимому, видимый фокус, aria-метки у иконок и звёзд, alt у фото, управление лайтбоксом с клавиатуры.
